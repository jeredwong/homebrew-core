# Contributing and AI use

This independent sandbox preserves Homebrew's BSD license for copied material.
Human contributors own every submitted change and must review generated reports,
code and prose. Disclose the AI tool/model and what it produced in the initial PR.
State which verification was performed by a human and which by automation.
Never claim human review, source builds, or hosted controls that did not occur.
Do not credit AI as a commit author, co-author, committer or signatory.
If material is submitted to Homebrew, follow its current CONTRIBUTING.md in full,
including answering maintainer questions yourself without AI and the one-open-
AI-assisted-PR limit for non-maintainers. This project posts nothing to Homebrew.

Run the commands in AGENTS.md. Include evaluation changes and preserve failures.
Changes to permissions, scripts, prompts, model or evidence require human review.
The repository owner is accountable for enabling and operating the workflow.
Before deployment record the owner's GitHub handle in OPERATORS.md, configure
protected-branch required review where supported, and verify credential scope.
